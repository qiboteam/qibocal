### `standard_rb`

Source: `src/qibocal/protocols/randomized_benchmarking/standard_rb.py`

Description: The data acquisition stage of Standard Randomized Benchmarking. 1. Set up the scan 2. Execute the scan 3. Post process the data and initialize a standard rb data object with it. Args: params: All parameters in one object. platform: CalibrationPlatform the experiment is executed on. target: list of qubits the experiment is executed on. Returns: RBData: The depths, samples and ground state probability of each experiment in the scan.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `depths` | `list | Depthsdict` | yes | A list of depths/sequence lengths. If a dictionary is given the list will be build. |
| `niter` | `int` | yes | Sets how many iterations over the same depth value. |
| `uncertainties` | `float | None` | no | Method of computing the error bars of the signal and uncertainties of the fit. If ``None``, it computes the standard deviation. Otherwise it computes the corresponding confidence interval. Defaults `None`. |
| `seed` | `int | None` | no | A fixed seed to initialize ``np.random.Generator``. If ``None``, uses a random seed. Defaults is ``None``. |
| `nshots` | `int` | no | Just to add the default value. |
